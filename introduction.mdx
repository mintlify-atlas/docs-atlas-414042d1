Willet is a task tracker built for AI agents. Instead of a web UI, it exposes a complete set of [MCP](https://modelcontextprotocol.io/) tools your AI assistant can call directly — creating tasks, tracking progress, linking dependencies, and visualizing your project without leaving the terminal. Each project gets its own SQLite database, so data stays local, isolated, and easy to back up.

## Two ways to run

Willet runs locally on your machine or as a self-hosted server for your team.

| | **Local** | **Self-hosted** |
|---|---|---|
| **Users** | Single user | Multi-user with per-user auth |
| **Install** | `npm install` | Docker |
| **Best for** | Personal use with Claude Code | Teams sharing a task server |

## How it works

Your AI agent communicates with Willet through standard MCP tool calls. When your agent calls a tool — such as creating a task or searching for related issues — Willet handles all the database operations and returns structured results the agent can reason about.

Each project is stored as a separate SQLite database under `~/.willet/projects/<id>/tasks.db`. A registry database at `~/.willet/registry.db` maps your working directories to their respective projects, so Willet always knows which project is active based on where you are.

Semantic search is powered by a local [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) ONNX embedding model. It runs entirely on your machine — no data leaves your environment.
