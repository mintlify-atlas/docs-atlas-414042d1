## What Willet does

Willet is a task tracker designed specifically for AI coding agents. Instead of a web UI, it exposes a complete set of MCP tools your AI assistant can call directly — creating tasks, tracking progress, linking dependencies, and visualizing your project without switching context.

<CardGroup cols={2}>
  <Card title="Tasks and epics" icon="list-check" href="/concepts/tasks">
    Create tasks, bugs, features, and epics with priorities, estimates, tags, due dates, and full change history.
  </Card>
  <Card title="Dependencies and links" icon="diagram-project" href="/tools/links-comments">
    Link tasks as blocking, related, or duplicate and traverse the dependency graph across multiple hops.
  </Card>
  <Card title="Visualizations" icon="chart-kanban" href="/tools/visualizations">
